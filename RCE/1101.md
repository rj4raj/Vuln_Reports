### Title
Remote Command Execution (RCE) via CMD Parameter

### Vulnerability Type
Remote Code Execution (RCE)

### Summary
While testing the application, I noticed that the `cmd` parameter appears to be executed directly by the server.
By supplying a system command through this parameter, I was able to execute operating system commands and view their output in the application's response.
To verify this, I executed the command:

`cat /etc/passwd`
The server returned the contents of the `/etc/passwd` file, confirming that arbitrary commands can be executed on the underlying system.

### Vulnerable Endpoint
`https://kzlabs.com/cmd`

### Steps to Reproduce
1. GO to the `https://kzlabs.com/1101.php` page.
2. Identify the `cmd` parameter in the request.
3. Intercept the request using Burp Suite.
4. Modify the value of the `cmd` parameter to: `cat /etc/passwd`
5. Send the request.
6. Observe that the application executes the command and returns the output in the response.

### Payload Used
`cat /etc/passwd`

### Impact
An attacker can execute commands on the server with the privileges of the web application.
This could allow an attacker to:
- Read sensitive files from the server.
- Access application secrets and credentials.
- Modify or delete data.
- Interact with internal services.
- Potentially gain full control of the affected server.

## Remediation
1. The application should not execute commands provided by users.
2. Validate and restrict user input before it is processed.
3. Limit what the web server is allowed to access on the system.
4. Review the command execution functionality and ensure only intended actions can be performed.
