# Vulnerability Reports

This repository contains security vulnerability reports and proof-of-concept findings discovered during lab practice and authorized security testing.

## Vulnerabilities Covered

- Reflected Cross-Site Scripting (XSS)
- Stored Cross-Site Scripting (XSS)
- Blind Cross-Site Scripting (Blind XSS)

## Platforms

- KrazePlanet Labs
- KZLabs

## Report Structure

Each report contains:

- Summary
- Vulnerable Endpoint
- Steps to Reproduce
- Payload Used
- Proof of Concept
- Impact
- Remediation

## Disclaimer

These reports are created strictly for educational purposes and authorized security testing environments.
